# 0x07. Pointers, arrays and strings

This project focuses on advanced pointer usage, memory manipulation, and string handling in C.

## Tasks

0. Fill memory with constant byte
1. Copy memory area
2. Locate character in string
3. Get length of prefix substring
4. Search string for any set of bytes
5. Locate substring
6. Print chessboard
7. Print diagonal sums of matrix

## Requirements

- Betty style
- No global variables
- Max 5 functions per file
- Use _putchar where required
- Compile with:
  gcc -Wall -Werror -Wextra -pedantic -std=gnu89
