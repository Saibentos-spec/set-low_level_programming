# 0x08. Recursion

This project focuses on recursion in C programming.

## Tasks

0. Print string using recursion
1. Print string in reverse using recursion
2. Get string length using recursion
3. Calculate factorial using recursion
4. Power function using recursion
5. Square root using recursion
6. Prime number check using recursion

## Requirements

- No loops allowed
- No static variables
- Use recursion only
- Use _putchar for output
- Compile with:
  gcc -Wall -Werror -Wextra -pedantic -std=gnu89
