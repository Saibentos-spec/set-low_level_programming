# 0x05. Pointers, arrays and strings

This project covers the fundamentals of pointers, arrays, and strings in C.

## Tasks

0. Function that updates value to 98 using pointer
1. Function that swaps two integers
2. Function that returns string length
3. Function that prints a string
4. Function that prints string in reverse
5. Function that reverses a string
6. Function that prints every other character
7. Function that prints half of a string
8. Function that prints array elements
9. Function that copies a string

## Requirements

- Betty style
- No global variables
- Max 5 functions per file
- Use `_putchar` only (except where allowed)
- Compiled with:
  `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
