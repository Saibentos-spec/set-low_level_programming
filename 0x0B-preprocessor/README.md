# 0x0B. C - Preprocessor

## 📌 Description
This project focuses on understanding and using the C preprocessor.  
It covers object-like macros, function-like macros, and built-in macros.

All tasks are implemented following strict project requirements including:
- Betty coding style
- No global variables
- Proper file organization
- Compilation with strict flags

---
